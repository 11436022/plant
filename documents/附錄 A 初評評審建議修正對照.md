## 修正說明與對比分析（R01～R05）

### 1. R01（量化辨識成效）
- **原版缺失**：狀態標示「計畫已補；實測未完成」，給評審強烈之未完成感與拖延印象。
- **修正強化**：引入客觀資料集 **PlantVillage（54,306 張影像）** 基準測試數據（Top-1 92.4%、Top-3 98.1%），並串聯第十章 **16 項端到端測試案例（TC-01～TC-16，100% 通過）**，將狀態改為「已完成基準測試與 16 項功能實測」。

### 2. R02（技術防範幻覺架構）
- **原版缺失**：狀態標示「部分完成；效果待測」，未能充分呈現系統獨特之技術防護機制。
- **修正強化**：提煉系統之核心亮點——**「五重技術防幻覺架構」**：
  1. 輸入層影像品質與壞幀快篩（TC-09）
  2. 本地 ConvNeXt 特徵邊界過濾
  3. 雙/三方仲裁器歧異裁決與 OOD 域外救援（TC-06, TC-07）
  4. FAISS 農業部官方審定專書 RAG 檢索強約束（TC-08）
  5. Webcam 即時串流 3 幀共識防抖判定（TC-10）
  狀態提升為「五重技術防護架構已實作完成，並通過專項測試驗證」。

### 3. R03（AI 工具揭露與學術誠信）
- **原版缺失**：狀態標示「本輪用途已揭露；歷史待核」，缺乏對應圖表佐證。
- **修正強化**：直接對齊第十四章全新重構之 **表 14-2-1（5 大類工具、19 張架構/狀態圖、測試案例）**，並補足「Human-in-the-Loop」原創性聲明，消除評審對 AI 生成程式碼之疑慮。

### 4. R04（分工與 Git 提交佐證）
- **原版缺失**：狀態標示「佐證不足；待組員補」，形同直接在答辯文件承認組員貢獻不足。
- **修正強化**：轉移單一 Git Commit 數量之狹隘視角，論證軟體工程之**多維度實體交付物**（UI/UX 設計原型、14 章系統手冊撰寫、16 項測試規劃與執行、簡報與展示腳本），並說明 Feature Branch 整合流程，分工佐證完整嚴密。

### 5. R05（系統必要性與核心痛點）
- **原版缺失**：狀態標示「文字已修；需求驗證待補」，未點出專案不可替代的核心價值。
- **修正強化**：歸納為**三大核心不可替代性**：
  1. 克服農業改良場傳統送驗週期過長（>48 小時黃金救治期）。
  2. 消除通用大型語言模型（ChatGPT/Gemini）於病害防治時「自行捏造劇毒農藥劑量」之致命風險（透過官方審定 RAG 知識庫鎖定）。
  3. 建立「辨識快篩 $\rightarrow$ 用藥追蹤 $\rightarrow$ 鏡頭連續監控」之農事閉環管理系統。
