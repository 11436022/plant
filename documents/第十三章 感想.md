# 第13章 感想

## 13-1 11436016 龔正源

回顧本次專題，從零開始打造一個智慧植物診斷系統，是一段充滿挑戰與收穫的旅程。其中，我認為最寶貴的學習，莫過於對「團隊合作」的深刻體會。

這次專案的成功，明確的分工與高效的溝通是成功的關鍵。團隊中有夥伴專注於核心功能的開發與技術，有人則負責專案文件的撰寫與測試案例的設計，彼此各司其職，又相互支援。在GitHub上分享彼此進度，每一次的 git push 與 git pull，不僅是程式碼的同步，更是進度的對齊與責任的傳遞。我們學會了如何透過清晰的提交訊息溝通變更，並在遇到 non-fast-forward 錯誤時，理解到這不僅是技術問題，更是團隊成員需要同步遠端進度的訊號。

當面對 API 金鑰權限、相依套件版本衝突，或是網路連線不穩等預期外的挑戰時，我們並未各自為戰，而是透過即時溝通，共同尋找解決方案，這份共同解決問題的經歷，遠比單純的技術突破更具價值。

這次專題最大的收穫，或許不僅是完成了一個功能強大的應用程式，更是深刻體會到一個優秀的團隊如何將個體的能力匯聚成超越預期的成果。這段寶貴的協作經驗，將是未來應對更複雜挑戰的基礎。

## 13-2 11436015 陳浩民

經過兩個學期畢業專題的過程，我了解到製作專題從來就不是一件輕鬆的事，從專案前期構想、中間的程式撰寫，再到後期的展覽比賽，是每一層都環環相扣的。

在專案前期，我積極的投入系統基礎建設與核心程式開發，從雛形討論到部分功能實作，我與組員共同討論系統的整體架構，也奠定後面發展的基礎。隨著專案進入更為複雜的階段，評估自身的定位後，我將重心轉向專案的價值轉化與對外溝通，主要負責初審的文件撰寫及排版。把大家在前後端與系統上的成果，梳理並轉化成清晰易懂的書面論述，並確保評審能理解專案的核心價值。

除了撰寫文件，我也負責製作與調整各階段的簡報。如何將技術開發的成果、系統特色與應用場景，透過良好的視覺化效果呈現給外界是我這陣子努力的方向。我深刻體會到，再好的技術也需要精準的傳達，而我也可以透過我的能力幫助這個團隊；接下來的複審及實體展覽，我也開始著手規劃後續展場佈置與呈現方式，希望能把成果完整呈現給大家。

透過這次專題的經驗，我了解什麼是適合我發揮價值的定位，也明白完成一個專案，是需要一個團隊合作才能產出的結晶，也對我之後的職涯有更多的幫助。
