# 表 5-1-1 功能需求清單表

## 表 5-1-1 功能需求清單表

| 編號 | 需求 | 對應程式 |
| --- | --- | --- |
| FR-01 | 使用者可註冊、完成信箱驗證、登入、登出及重設密碼。 | auth.py、LoginActivity、RegisterActivity、ResetPasswordActivity |
| FR-02 | 使用者可拍照或選取植物圖片及指定名稱，依階層式瀑布流架構執行「本地 ConvNeXt 優先快篩，未命中則由 Gemini 兜底」之精準診斷結果。 | prediction.py、ai.py (predict_convnext_fast_screen, _call_gemini_fallback)、UploadActivity、DiagnoseProgressActivity |
| FR-03 | 系統依階層式架構執行本地 ConvNeXt 特徵快篩，未達 70% 信心度門檻則由 Gemini 進行兜底推論，並結合 FAISS 向量知識庫與農業部資料檢索校驗防範模型幻覺。 | ai.py、rag.py、ground_diagnosis_in_database |
| FR-04 | 使用者確認診斷後，系統才保存圖片、結果與備註；若診斷為未知作物或無法判定病害，系統嚴格禁止存入病歷日記，僅保留結果有誤（回饋）選項。 | POST/diaries/confirm/{prediction_id}、plant_diary |
| FR-05 | 使用者可查詢、檢視、編輯個人備忘筆記（user_note）及刪除個人診斷紀錄。 | GET／PATCH／DELETE /diaries、HistoryListActivity、HistoryDetailActivity |
| FR-06 | 使用者可啟動單株或多區域 Webcam 定時監控。 | webcam.py、WebcamActivity、MultiPlantActivity、MonitoringScheduler |
| FR-07 | 系統只在連續影格結果一致且通過資料覆核時建立警報，並支援聲音、瀏覽器、Email、確認與刪除。 | webcam.py、webcam.html、webcam_alert |
| FR-08 | 管理員可檢視統計儀表板，並搜尋及分頁瀏覽診斷紀錄。 | admin.py、dashboard.html |
| FR-09 | 管理員可檢視全站診斷紀錄；為維護資料完整性與模型標註集，管理後台不提供紀錄刪除功能。 | admin.py、dashboard.html |
| FR-10 | 管理員可查詢及搜尋使用者列表。 | GET /admin/users/、users.html |
| FR-11 | 使用者可針對 AI 診斷錯誤之紀錄提交反饋糾錯（包含植物名或病名之更正建議與錯誤標記）。 | feedback.py、DiagnosisFeedbackActivity、diagnosis_feedback |
| FR-12 | 管理員可審核使用者糾錯反饋、進行人工標註確認，並將標註數據匯出為 JSONL 格式訓練集供本地 ConvNeXt 模型持續迭代重訓。 | admin.py、feedback.html、export_training_data.py |
