# 表 3-2-1 系統軟硬體需求表

## 表 3-2-1 系統軟硬體需求表

| 類別 | 需求 |
| --- | --- |
| 使用者端 | Android 8.0以上手機或模擬器、網路連線、相簿讀取權限。 |
| 伺服器端 | Python 3.10以上、FastAPI、Uvicorn、Pillow、Google GenAI SDK (google-genai)、SQLAlchemy、PyMySQL、FAISS 向量庫、PyTorch / torchvision (本地自訓 ConvNet 模型)。 |
| 資料庫 | MySQL 關聯式資料庫，包含 crop、disease、pests、user、plant_diary、user_one_time_tokens、webcam_alert 與 diagnosis_feedback (8 大資料表)。 |
| 部署 | 可使用 Dockerfile 建置 plant-backend 映像檔，docker-compose 掛載 static/uploads。 |
| 外部服務 | Google Gemini 2.5 Flash API、Gmail SMTP 郵件服務、農業部植物保護開放資料平台、中央氣象署 CWA 氣候開放資料。 |
