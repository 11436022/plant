# 表 5-3-1 註冊

## 表 5-3-1 註冊

| 使用個案名稱：使用者註冊 | 使用個案名稱：使用者註冊 |
| --- | --- |
| 行為人 | 新使用者 |
| 前提 | 使用者尚未擁有App帳號 |
| 結束狀態 | 系統成功建立一個狀態為「未驗證」的新帳號 |
| 事件路徑： | 事件路徑： |
| 動作 | 系統回應 |
| 在登入頁面點擊「點此註冊」。 | 畫面跳轉至註冊畫面。 |
| 依序輸入「帳號名稱」、「Gmail地址」及「密碼」。 | 系統即時檢查輸入格式是否符合需求。 |
| 點擊「完成註冊」按鈕。 | 後端伺服器建立新帳號資料。 |
| 畫面顯示「註冊成功，請至您的信箱收取驗證信」 | 發送驗證信至註冊信箱。 |
