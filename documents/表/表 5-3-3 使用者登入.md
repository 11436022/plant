# 表 5-3-3 使用者登入

## 表 5-3-3 使用者登入

| 使用個案名稱：使用者登入 | 使用個案名稱：使用者登入 |
| --- | --- |
| 行為人 | 已註冊的使用者 |
| 前提 | 使用者已擁有一個（且最好是已驗證的）帳號。<br>App 目前處於登出狀態。 |
| 結束狀態 | 使用者成功登入 App，並被導向個人化的主畫面。 |
| 事件路徑： | 事件路徑： |
| 動作 | 系統回應 |
| 在登入畫面輸入「使用者名稱」與「密碼」。 | (無系統回應) |
| 點擊「登入」按鈕。 | App 將帳號密碼傳送至後端進行驗證。 |
| 驗證成功。 | 跳轉至 App 主畫面。 |
| 驗證失敗。 | 顯示「帳號或密碼錯誤」的提示。 |
