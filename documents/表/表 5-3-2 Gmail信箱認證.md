# 表 5-3-2 Gmail信箱認證

## 表 5-3-2 Gmail信箱認證

| 使用個案名稱：Gmail信箱驗證 | 使用個案名稱：Gmail信箱驗證 |
| --- | --- |
| 行為人 | 新使用者 |
| 前提 | 1. 使用者已完成註冊，帳號處於「未認證」狀態<br>2. 使用者已在自己的 Gmail 收到來自系統的驗證信 |
| 結束狀態 | 使用者的帳號狀態被更新為「已驗證」，可以使用 App 的所有功能。 |
| 事件路徑： | 事件路徑： |
| 動作 | 系統回應 |
| 在手機或電腦上打開 Gmail，找到驗證信。 | (無系統回應) |
| 點擊信件內文中的「驗證我的帳號」連結。 | 手機或電腦的瀏覽器開啟一個新分頁。 |
| 該分頁顯示「帳號驗證成功！」的訊息。 | 後端伺服器同步將該使用者的帳號狀態更新為「已驗證」。 |
