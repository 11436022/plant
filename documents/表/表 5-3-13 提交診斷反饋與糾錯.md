# 表 5-3-13 提交診斷反饋與糾錯

## 表 5-3-13 提交診斷反饋與糾錯

| 使用個案名稱：提交診斷反饋與糾錯 | 使用個案名稱：提交診斷反饋與糾錯 |
| --- | --- |
| 行為人 | 一般使用者 |
| 前提 | 使用者完成診斷，包含兩類情境：(1) 診斷結果為未知或無法判定，系統僅提供反饋糾錯選項；(2) 診斷雖有確診結果，但使用者認為推論有誤。 |
| 結束狀態 | 糾錯反饋記錄與臨時影像轉存並成功寫入 diagnosis_feedback 資料表。 |
| 事件路徑： | 事件路徑： |
| 動作 | 系統回應 |
| 在診斷結果頁點擊「回報錯誤／反饋糾錯」按鈕。 | 開啟糾錯對話框，提供勾選錯誤類型（植物名或病名錯誤）與輸入修正建議。 |
| 勾選錯誤類型、填寫修正建議後點擊「送出反饋」。 | 後端接收反饋，將暫存圖片轉存至正式目錄，寫入資料表並清除暫存快取。 |
