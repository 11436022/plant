# 表 5-1-2 非功能需求清單表

## 表 5-1-2 非功能需求清單表

| 編號 | 需求 | 說明 |
| --- | --- | --- |
| NFR-01 | 安全性 | JWT、密碼雜湊及一次性 token 已實作；正式環境仍須為 /admin 路由套用管理員權限保護。 |
| NFR-02 | 可維護性 | 後端分 routers、services、schemas、db；Android 依 Activity 分頁。 |
| NFR-03 | 可部署性 | 提供 Dockerfile、docker-compose 與 .env.example。 |
| NFR-04 | 可用性 | App以按鈕與進度頁呈現主要流程，降低操作難度。 |
| NFR-05 | 可靠性 | AI 回傳需通過結構、清單、作物關聯、信心門檻與來源檢查；未通過時標示需人工確認。 |
| NFR-06 | 可追溯性 | 診斷結果保留 reference_source、reference_url 與 reference_record_id，供使用者或管理者查核。 |
