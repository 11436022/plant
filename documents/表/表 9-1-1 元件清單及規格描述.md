# 表 9-1-1 元件清單及規格描述

## 表 9-1-1 元件清單及規格描述

| 元件 | 檔案 | 功能 |
| --- | --- | --- |
| 應用程式入口 | app/main.py | 建立FastAPI、掛載static、載入路由與啟動schema修補。 |
| 認證路由 | app/routers/auth.py | 註冊、登入、取得個人資料、驗證信、忘記密碼與重設密碼。 |
| 預測路由 | app/routers/prediction.py | 接收植物圖片上傳、驗證格式與尺寸、調度多層AI快篩推論並建立TTL暫存預測結果。 |
| 日誌路由 | app/routers/diaries.py | 提供診斷暫存確認儲存、分頁歷史清單查詢、單筆詳細資訊檢視、備註更新與刪除。 |
| 診斷回饋路由 | app/routers/feedback.py | 接收農友對AI判定之作物或病蟲害校正回饋，記錄錯誤標註資料以支援模型主動學習。 |
| 後台管理路由 | app/routers/admin.py | 提供管理員儀表板4項KPI統計、使用者與日誌維護、回饋審核標註、特徵快取重建與微調觸發。 |
| AI診斷服務 | app/services/ai.py<br>app/services/convnext.py<br>app/services/visual_memory.py<br>app/services/rag.py | 整合本地ConvNeXt快篩、Grad-CAM葉片驗證、768維視覺記憶檢索與Gemini 3.8 Flash兜底，並串接MySQL與FAISS RAG生成具出處防治建議。 |
| 知識檢索服務 | app/services/knowledge.py | 查詢作物、病害與蟲害百科知識；關聯農業部圖庫開放資料，確保診斷處置措施具備可追溯資料來源。 |
| 檔案管理服務 | app/services/files.py | 安全檔名、圖片類型檢查與公開圖片網址。 |
| 郵件通知服務 | app/services/email.py | 封裝SMTP非同步郵件傳輸協議，負責發送新用戶驗證信、密碼重設代碼與Webcam異常警報信。 |
| Webcam服務 | app/routers/webcam.py<br>app/services/webcam.py | 影格驗證、連續3次相符共識、警報建立、Email通知、確認與刪除。 |
| Android API | PlantApiService.kt<br>AuthInterceptor.kt | 以Retrofit封裝RESTful API呼叫，並透過OkHttp攔截器自動注入Bearer JWT Token與處理過期重導。 |
| Android畫面 | 各Activity.kt | 登入、註冊、首頁、即時拍照、診斷結果、歷史紀錄、Webcam自訂監控區域與設定。 |
