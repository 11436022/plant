# 表 9-1-1 元件清單及規格描述

## 表 9-1-1 元件清單及規格描述

| 元件 | 檔案 | 功能 |
| --- | --- | --- |
| 應用程式入口 | app/main.py | 建立FastAPI、掛載static、載入路由與啟動schema修補。 |
| 認證路由 | app/routers/auth.py | 註冊、登入、取得個人資料、驗證信、忘記密碼與重設密碼。 |
| 日誌路由 | app/routers/diaries.py | 圖片上傳診斷、查詢、更新與刪除個人日誌。 |
| AI服務 | app/services/ai.py | 呼叫 Gemini 進行影像初判，再以資料庫清單、關聯、信心門檻與來源欄位校驗結果。 |
| 知識服務 | app/services/knowledge.py | 查詢作物、病害與蟲害知識；正式診斷建議以可追溯資料來源為準。 |
| 檔案服務 | app/services/files.py | 安全檔名、圖片類型檢查與公開圖片網址。 |
| Android API | PlantApiService.kt | Retrofit註冊、登入、上傳圖片、查詢歷史。 |
| Android畫面 | 各Activity.kt | 登入、註冊、首頁、上傳、診斷結果、歷史紀錄<br>與設定。 |
| Webcam服務 | app/routers/webcam.py、app/services/webcam.py | 影格驗證、連續結果共識、警報建立、Email通知、確認與刪除。 |
