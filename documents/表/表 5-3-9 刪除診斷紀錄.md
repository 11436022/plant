# 表 5-3-9 刪除個人診斷紀錄

## 表 5-3-9 刪除個人診斷紀錄

| 使用個案名稱：刪除個人診斷紀錄 | 使用個案名稱：刪除個人診斷紀錄 |
| --- | --- |
| 行為人 | 一般使用者 |
| 前提 | 使用者已完成身分驗證並登入 Android 行動端，並位於個人植物診斷歷史紀錄清單。 |
| 結束狀態 | 指定之個人植物診斷日誌已自使用者的日誌列表與資料庫安全移除。 |
| 事件路徑： | 事件路徑： |
| 動作 | 系統回應 |
| 使用者於歷史紀錄清單中點擊欲刪除之診斷紀錄「刪除」圖示，並於確認彈窗中點選確定。 | Android 前端發送 DELETE API 請求（/diaries/{diary_id}）至後端伺服器，後端校驗紀錄擁有者權限後自 plant_diary 資料表中安全移除，並即時刷新個人歷史列表。 |
