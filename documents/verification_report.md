## 必須保留的限制

1. **AI 校驗不是正確率保證。** 名稱白名單、作物關聯、來源欄位及連續影格只能降低特定錯誤；模型仍可能把影像誤判成資料庫中另一個合法類別。來源欄位完整不等於原始內容正確、現行處方核准或專家簽核。模型信心值不是辨識準確率。
2. **尚無專業複核簽核流程。** `requires_review` 是待確認標記；一般使用者註記不是重新診斷。unknown／需複核結果可保存，但不得觸發自動警報。
3. **監控與暫存仍為單程序記憶體。** 需單一 worker；重啟會失去連續計數及待確認預測。過期預測採後續請求觸發清理。未傳工作階段／區域的舊客戶端使用相容預設值，不能視為多區域隔離完成。
4. **Android 與瀏覽器功能不同。** 瀏覽器監控整幅畫面，Android 實作單株／多區域裁切；警報查詢、確認及刪除目前僅有瀏覽器畫面。Android 相關 API 宣告不代表管理畫面已完成。
5. **郵件不是可靠投遞佇列。** 警報先保存，再嘗試寄信。`email_sent` 不證明使用者實際收件；寄信狀態寫入失敗也可能顯示 false。資料庫提交結果不明時保留圖片，可能留下需人工核對的孤立檔案。尚未建立自動重送與投遞追蹤機制。
6. **來源版本仍需維護。** `tree-local-*` 是本地內容指紋，不是官方案例 ID；資料集網址未必直達個別案例。RAG 清單記錄來源雜湊，但載入器沒有再次比對現存 `data.json` 的雜湊，維護者須核對並重新建庫。舊正式資料及索引未於本次更新。
7. **登出不代表伺服器撤銷所有 JWT。** 目前清除客戶端登入資料／管理 Cookie；已發出的有效 JWT 仍依期限失效。正式環境須另評估權杖撤銷需求。
8. **網路圖片測試未於本次執行。** 現有腳本只有三張番茄範例，網址未固定版本；本次未下載、標註或呼叫真實 Gemini。不能引用為一般作物準確率或完整 RAG 驗收證據。
