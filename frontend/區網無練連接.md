# Android 區域網路連線說明

## 無線偵錯與後端連線

Android Studio 的裝置配對與 App 呼叫後端是兩種不同的連線，配對成功不代表手機已能存取 API。

1. 手機與電腦連到可互通的可信任網路。公共網路可能開啟裝置隔離；可改用自己的熱點，但仍須確認裝置之間能互通。
2. 在 Android 的開發人員選項開啟無線偵錯，選擇使用配對碼配對裝置。
3. 在 Android Studio 使用 Pair Devices Using Wi-Fi，依裝置顯示的資訊配對。
4. 在電腦執行 `ipconfig`，確認目前網卡的 IPv4 位址。
5. 在 `frontend/plantdoctor/local.properties` 設定 `WIFI_HOST=電腦的IPv4位址`，重新建置 App。不要提交本機 SDK 路徑或私有設定。
6. 啟動後端：`python main.py`。確認監聽位址與連接埠設定允許區域網路裝置存取。
7. 使用手機瀏覽器檢查 `http://電腦的IPv4位址:8000/docs`。此步只能驗證 HTTP 可連線，不代表資料庫、Gemini 或登入已通過測試。

防火牆應只允許必要的程式、連接埠及可信任私人網路範圍，不要直接關閉整個防火牆。正式外網部署需使用 HTTPS；不要透過公共網路明文傳送密碼或權杖。

## USB 或已連線裝置的 ADB 轉送

確認 `adb devices` 能看到已授權的目標裝置，再執行：

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" reverse tcp:8000 tcp:8000
```

實際 SDK 安裝位置不同時，請使用該位置的 adb。若有多個裝置，使用 `adb -s 裝置序號 reverse tcp:8000 tcp:8000` 指定目標。

ADB 轉送須搭配 App 指向手機端 `127.0.0.1:8000` 的設定；使用區域網路 IP 則是直接連線，兩者不要混用。裝置重新連線後，先用 `adb reverse --list` 確認規則，必要時重新建立。

## 連線問題檢查

- IP 位址變動：重新查詢網卡位址，更新 WIFI_HOST 並重新建置。
- 無線偵錯中斷：確認配對、裝置授權與網路狀態。
- API 無法存取：確認後端程序、監聽位址、連接埠、防火牆及裝置隔離設定。
- API 能連線但功能失敗：依 HTTP 回應與後端紀錄檢查登入、資料庫及外部服務。
- 瀏覽器 Webcam：相機權限通常要求 localhost 或 HTTPS；區域網路 HTTP 可連線不代表可啟用相機。

以上是排查順序，不保證特定成功率或完成時間。
