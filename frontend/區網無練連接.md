📱 區網全無線開發：四大黃金步驟總結

### 第一步：網路環境與手機配對 (確保在同個世界)

統一 WiFi：

##### 確保手機和電腦連接在同一個 WiFi 網路

（若在公眾場所，直接用手機開熱點給電腦連是最純淨、最安全的作法）。

##### 手機端開啟：進入手機的 開發人員選項 ➡️ 開啟 無線除錯 ➡️ 點擊 使用配對碼配對裝置，停留在顯示 6 位數配對碼的畫面(要停留在這才找的到)。

Android Studio 端連線：

##### 點擊右上角裝置下拉選單 ➡️ Pair Devices Using Wi-Fi。

##### 輸入手機上的 6 位數配對碼完成配對。

結果：這時 Android Studio 就能直接無線 Run 程式碼到你手機了！



### 第二步：查出電腦區網門牌 (找到後端在哪)

在電腦的終端機（Terminal / 命令提示字元）輸入：

Windows: ipconfig

Mac / Linux: ifconfig

找到你目前連線的無線網卡（IPv4 位址），這就是你電腦在區網裡的真实 IP。

💡 例如：192.168.0.105



### 第三步：修改 Android 端的通訊網址 (對準新門牌)

##### 現在只要把API裡的第136行中的"輸入你的IP"改成你自己的IP

必須把 App 裡面所有代表「電腦本機」的舊代稱（localhost、127.0.0.1、10.0.2.2），通通換成剛才查到的電腦真實 IP。

修改 API 主網址 (BASE\_URL)：

Kotlin

// 舊的有線/模擬器寫法：http://localhost:8000/api/v1/

val BASE\_URL = "http://192.168.0.105:8000/api/v1/"

修改圖片/靜態資源網址轉換 (fixImageUrl)： 在方法最上方利用字串插值，將變數鎖定為你的真實 IP：

Kotlin

val computerWifiIp = "192.168.0.105" // 程式底下的 $computerWifiIp 會自動同步帶入

並確保裡面同時包含 /uploads/ 和 /static/ 兩個後端路由的安全防禦。



### 第四步：解鎖後端接收權限 (允許外來手機連線)

後端開啟 0.0.0.0 監聽：啟動後端伺服器時，必須下指令允許接收來自區網內其他設備（手機）的請求，而不能只鎖在 127.0.0.1。

### 以 FastAPI 為例：uvicorn main:app --host 0.0.0.0 --port 8000

電腦防火牆防禦：如果後端還是沒動靜，記得去把電腦的防火牆暫時關閉，或將 8000 Port 加入允許名單。

💡 未來遇到斷線時的「快速急救包」

之後如果隔天起來發現又連不上了，只要檢查以下 3 個地方，99% 都能在一分鐘內修好：

#### IP 變了：

##### 家裡的 WiFi 每次重新連線，分配給電腦的 IP 可能會微調（例如今天 105，明天變 106）。這時只要重新 ipconfig 查一下，去 Android 專案裡把那行 IP 數字改掉就行了。

#### 無線除錯睡著了：

##### 有時候手機重開機後無線除錯會關閉。去手機設定裡把無線除錯關掉再重新打開，Android Studio 就會秒連回去了。

#### 防干擾大絕招：

##### 在學校、咖啡廳、公用宿舍通常會阻擋設備互連。直接手機開熱點給電腦連，就能 100% 破解公共網路的連線限制！
